# 阿洁的旅行工具箱使用教程

阿洁的旅行工具箱用于集中管理《明日方舟》相关的网站、本地程序、文件夹和资料入口。每个入口都称为一个“项目”。工具箱以本地数据为主：不登录账号、不联网也能使用项目管理、启动和配置导入导出等基础能力。

> **先了解路径规则**：以 `http://` 或 `https://` 开头的目标会作为网站打开；其他目标会作为本地路径启动。相对路径以工具箱的数据根目录为基准，推荐统一写成 `tools/程序目录/程序.exe`，并使用 `/` 作为分隔符。

## 1. 界面快速认识

- 左侧“分类”拉出栏用于切换分类；展开后点击页面空白处即可关闭。
- 顶部搜索框可按中文、拼音、英文、缩写、分类和简介查找当前配置源内的项目。按 `Ctrl + K` 可直接聚焦搜索框。
- 每张正方形卡片代表一个项目，包含项目类型、图标、名称、简介、收藏、编辑和启动入口。
- 顶部“添加项目”用于创建项目；“公告”和“使用教程”位于设置按钮左侧。
- 右上角“设置”集中放置导入导出、配置源、分类、背景、定时任务、快捷键、“默认配置源本地工具包下载”、更新和日志等功能。

“全部”显示当前配置源已注册的所有项目；“收藏”只显示已收藏项目。这两个都是系统分类，不能删除，也不会计入自定义分类。

## 2. 添加、编辑与启动项目

### 添加项目

1. 点击顶部“添加项目”。
2. 填写**名称**和**启动路径或网址**，两项必填。
3. 按需选择图标、填写分类和简介。
4. 点击保存，项目会加入当前配置源。

未填写分类的项目仍会出现在“全部”中，但不会出现在任何自定义分类下。

### 网站与本地工具

工具箱根据启动目标自动识别类型：

- `https://arkntools.app/`：网站，点击“启动”后交给系统默认浏览器打开。
- `tools/MAA/MAA.exe`：本地工具，点击“启动”后运行对应程序。
- `D:/Programs/example.exe`：绝对路径本地工具；仅适合确定不会迁移路径的个人配置。

本地目标不存在、被移动或路径写错时不能启动。编辑项目修正路径即可；工具箱不会修改、删除或更新该程序本体。

### 编辑、删除、收藏与复制

点击卡片右上角“编辑”可修改名称、目标、分类、简介、图标和高级启动项。

- 点击星标可收藏或取消收藏；收藏状态会随配置源导出。
- “删除此项目”只删除**当前配置源**中的项目记录，不会删除原程序、文件夹、网站或用户选取的原图。
- 编辑窗口的“导入到配置源”会把当前项目复制到另一个配置源；原项目保留。目标源缺少该分类时会自动补齐分类。

### 高级启动（仅本地工具）

本地工具默认和网站一样，只有一个“启动”按钮。编辑项目时勾选“启用高级启动项”并保存，卡片会显示“启动”和“高级启动”。

“高级启动”下拉菜单可以：

- **以管理员权限启动**：通过 Windows UAC 请求管理员权限。仅在工具确实要求管理员权限时使用。
- **自定义命令启动**：最多添加 20 条具名 CMD 命令。例如：

```cmd
tools/MAA/MAA.exe --debug
```

自定义命令在 Windows 中由 `cmd.exe /d /s /c` 执行，工作目录为工具箱的数据根目录，因此相对路径仍按同一规则解析。它可以执行任意系统命令，请只保存自己理解且信任的内容。

关闭“启用高级启动项”只隐藏按钮和菜单，不会删除已保存的命令；重新开启后可以继续使用。网站项目不会出现高级启动。

## 3. 图标、简介和分类

### 图标与简介

项目图标支持 PNG、JPG/JPEG、WebP、GIF、BMP 和 ICO。保存时工具箱会复制一份到自身托管目录；之后删除外部原图也不会影响卡片显示。

更换图标或删除项目后，如果旧托管图标不再被任何项目引用，工具箱会自动清理它。项目简介支持换行；卡片空间有限时，可在简介区域内滚动查看完整内容。

### 分类管理

在“设置”→“分类管理”中可新增或删除自定义分类。

- 分类名称本身就是分类标识，不能重复。
- 删除分类只会让其中项目变为“未分类”，不会删除项目。
- “全部”和“收藏”不可删除。

## 4. 搜索、排序与批量管理

### 搜索

搜索会在当前分类与当前配置源范围内进行，支持名称、分类和简介的模糊匹配，例如：

- 中文：`量角器`
- 拼音：`liang jiao qi` 或拼音片段
- 英文、缩写和数字：`MAA`

搜索结果仍受左侧当前分类约束；若要在整个配置源中查找，请先切换到“全部”。

### 拖拽排序

未进入批量管理时，可拖拽项目卡片调整顺序：

1. 从卡片图标、标题或空白区域按住并拖动；按钮、输入框和可滚动简介不是拖拽起点。
2. 拖到目标卡片上，目标卡片出现高亮后松开鼠标。
3. 两张项目卡片会交换位置，顺序立即写入当前配置源。

排序会在重启、切换分类和导入导出后保持。搜索或分类筛选时建议先回到“全部”再排序，避免误判可见项目的位置。

### 批量管理

点击“设置”→“批量管理”后，卡片会出现选择控件：

1. 勾选一个或多个项目。
2. 选择“移动到分类”“复制到分类”或“删除”。
3. 操作完成后点击“完成”退出批量管理。

“移动到分类”修改原项目分类；“复制到分类”创建副本并保留原项目；“删除”仅删除当前配置源记录。操作目标分类不存在时，可以在弹窗中直接创建。

## 5. 配置源与配置迁移

### 配置源

配置源是一套独立的清单，适合分开保存“日常使用”“测试”“不同模式”等项目组合。每个配置源拥有自己的项目、分类、卡片排序、快捷轮盘槽位和定时任务。

在“设置”→“配置源设置”中可以：

- 切换配置源；界面随后只显示该源项目。
- 新建配置源；可选择“创建时继承默认配置源”。继承会复制项目、分类和轮盘布局；定时任务定义也会复制，但全部默认暂停，避免意外执行。
- 删除自定义配置源；默认配置源不可删除。删除会移除该源的配置，并取消该源已注册的 Windows 定时任务，但不会删除它指向的程序文件。

### 导出配置

在“设置”→“导出配置”中选择一个配置源，即可生成 `.attconfig` 文件。该文件本质上是标准 ZIP 配置包，适合备份和跨设备迁移。

导出包含：项目、分类、收藏状态、排序、高级启动定义、自定义命令、托管图标、快捷轮盘槽位和定时任务定义。

导出**不包含**：工具箱程序、本地工具资源包或 `tools/` 内容、运行日志、背景图片、本机快捷键、轮盘位置和轮盘尺寸。

### 导入配置

在“设置”→“导入配置”选择 `.attconfig` 后，有三种模式：

- **增量导入（默认）**：创建一个新的配置源，不影响已有清单。
- **合并导入**：把导入项目与分类加入当前自定义配置源；原有排序保留，导入项目追加到后方。
- **覆盖导入**：用导入内容替换当前自定义配置源的项目和分类。

默认配置源不能被合并或覆盖。导入不会自动启动项目或自定义命令；导入的定时任务都会以暂停状态保存，需由你确认后手动启用。旧版配置包即使缺少分类、排序、轮盘、任务或新增字段，也会使用安全默认值继续导入；损坏的单个项目会跳过，其余内容仍可使用。

跨设备迁移本地项目时，目标设备仍要自行准备对应程序和依赖文件，并保证项目路径有效。

## 6. 背景图片

“设置”→“自定义背景图片”支持点击选图或直接拖入图片。支持 PNG、JPG/JPEG、WebP、GIF 和 BMP。

- 保存后会托管副本，外部原图删除不影响当前背景。
- 工具箱最多保留 10 张历史背景，点击缩略图即可切换。
- “恢复默认背景”会回到内置背景。
- 不再作为当前背景或历史背景引用的托管图片会自动清理。

## 7. 默认配置源本地工具包下载

安装程序不再内置 `tools/` 中的第三方本地工具。默认配置里的本地项目依赖**默认配置源本地工具包**，因此首次使用前应在“设置”→“默认配置源本地工具包下载”完成安装。

你可以从官方 GitHub Releases 下载资源包 ZIP 后点击“选择本地资源包”安装；也可以使用“下载并安装”。工具箱会按当前频道（测试版使用 beta，正式版使用 stable）查询 GitHub Releases，自动选择最新且与当前工具箱兼容的资源包。安装时会校验发布清单、ZIP 清单、路径和每个文件的 SHA-256 哈希。在线下载会显示百分比、已下载大小、总大小和速度；下载或查询阶段可取消，临时 ZIP 会自动清理。关闭窗口后再次打开，仍会显示同一下载任务的实时状态；重复点击下载会提示任务正在进行。校验和安装阶段为保护文件完整性，不支持取消。若在线查询超时、网络不可用或未发现兼容包，右上角气泡会说明原因；此时仍可使用本地 ZIP 安装。

资源包安装到用户数据目录，应用更新不会覆盖它。为保护你自己放进 `tools/` 的文件，检测到目录中存在工具箱未管理的文件时，工具箱会拒绝覆盖；请先自行备份并整理这些文件，再重试安装。

如果项目目标以 `tools/` 开头但资源包尚未安装，启动会提示你安装资源包，而不是静默失败。

## 8. 定时启动管理（Windows）

在“设置”→“定时启动管理”中可以保存多份定时任务。每个任务绑定一个配置源，并按队列顺序启动其中项目。

### 创建任务

1. 填写任务名称并选择配置源。新任务默认勾选“到达计划时间时启动工具箱”。
2. 选择时间配置：
   - **简易设置**：每天、每周或每月；每周可勾选多个星期。
   - **Cron 高级设置**：五段式 `分 时 日 月 周`，例如 `0 9 * * 1-5`。
3. 从项目选择器逐个加入启动队列。新项目默认在启动后等待 10 秒；每一步可以单独调整等待时间、删除或调整队列顺序。最后一步不会等待。
4. 按需开启触发选项后保存。

### 触发选项

- **启用此任务**：关闭后不会按时间触发。
- **到达计划时间时启动工具箱**：对于可转换的规则，工具箱会注册 Windows 任务计划。因此即使工具箱已关闭，到点后也能启动并执行。复杂 Cron 无法转换时会提示改用简易规则或关闭该项。
- **工具箱启动后立即执行一次**：只要任务已启用，每次工具箱启动就执行一次。
- **按固定间隔重复触发**：首次按计划触发后，再按设置的分钟间隔重复执行。

网站在队列中始终按普通方式打开。本地工具可为单个步骤选择管理员权限启动，届时 Windows 会显示 UAC 确认。多个任务同时触发会进入串行队列；同一任务还在运行或排队时不会重复启动。

## 9. 快捷键与快捷轮盘（Windows）

在“设置”→“快捷键与快捷轮盘设置”中开启全局快捷键。保存后，工具箱即使在后台也能响应；若快捷键已被系统或其他软件占用，会保留设置并提示未成功注册。

### 项目组合快捷键

选择配置源后，点击项目右侧“点击设置快捷键”，在录制窗口直接按下组合键或单个按键，例如 `Ctrl+Alt+M`。可用“清除快捷键”移除绑定。

项目快捷键按普通启动方式执行：网站打开浏览器，本地工具普通启动；不会自动使用管理员权限或自定义命令。普通单键也可以设置，但可能影响输入和其他程序，请谨慎使用。

### 快捷轮盘

轮盘是独立的透明无边框置顶窗口。开启轮盘后：

1. 点击“设置快捷键”，在录制窗口按下唤起键。
2. 从当前配置源选择圆心 1 项和外圈 9 项；槽位可留空。
3. 通过大小滑动条、九宫格位置和横纵百分比微调来调整外观；点击“预览位置与大小”可临时显示约 6 秒。
4. 保存并生效后，按唤起键即可在屏幕指定位置显示轮盘，点击图标启动对应项目。

再次按唤起键、按 `Esc`、右键点击或让轮盘失焦均会关闭轮盘。轮盘槽位属于配置源，会随 `.attconfig` 导入导出；全局快捷键、轮盘唤起键、位置和尺寸属于本机，不会随配置包迁移。

## 10. 公告与软件更新

### 公告

启动时，未读公告会自动弹出。公告由 Markdown 驱动：优先显示官方在线公告；网络不可用时使用最近缓存；没有缓存时显示程序内置公告。

远程公告固定存放在仓库根目录的 `content/announcement.md`。公告图片应使用 `https://raw.githubusercontent.com/ganhong1/JaeTravelToolbox/main/content/images/<文件名>` 形式的绝对 HTTPS 地址；请将图片保存到 `content/images/`，为每张新图使用新文件名，并且不要删除或覆盖已经被发布公告引用的旧图。

阅读到公告正文底部后，才可勾选“本版本更新前不再显示”。该选项只影响自动弹出，不会删除公告内容；随时可点击顶部“公告”重新查看。新版本会重新允许显示新公告。

### 软件更新

在“设置”→“软件更新”中可以：

- 选择是否在启动时检查更新。
- 选择更新源；当前仅提供官方 GitHub Releases，为未来官方镜像预留。
- 选择发现更新后是否自动下载。
- 选择退出工具箱时是否安装已经下载的更新。
- 手动检查、下载、取消下载，或重启后安装更新。下载时会显示进度、已下载大小、总大小和当前速度；取消会自动清理不完整的临时更新文件。

自动更新只在配置了官方 GitHub Releases 更新源的正式 NSIS 安装版中可用。源码开发环境、尚未配置官方更新源的发行包，或检查超时/失败时会明确提示，但不会阻塞工具箱继续使用；此时可前往 Releases 手动下载新版安装包。

## 11. 运行日志与问题反馈

在“设置”→“查看运行日志”中可查看本次运行的诊断事件。

- 可按 `DEBUG`、`INFO`、`WARNING`、`ERROR`、`CRITICAL` 筛选最低显示等级。
- 日志窗口打开时会实时刷新；关闭后立即停止刷新，以减少资源占用。
- 默认勾选“刷新时保持当前位置”，避免查看旧日志时被新记录拉回底部；可取消勾选以持续跟随最新记录。
- 点击“导出日志”后自行选择保存位置，生成便于反馈的 TXT 文件。

运行日志只在当前程序运行期间保存；每次重新启动都会清除上一轮日志。日志会尽量隐藏令牌、密码、Cookie、完整外部网址、深层本地路径、原始截图和窗口句柄等敏感信息；发送给他人前仍建议自行检查导出文件。

## 12. 数据位置与备份建议

源码开发时，数据根目录是工程目录；NSIS 安装版则使用系统分配的 Electron 用户数据目录。因此，不要假设安装版的配置一定与 EXE 同级。

主要可变数据包括：

```text
config/   配置源、背景、更新偏好、全局快捷键和资源包状态
items/    每个配置源内的项目记录
static/   工具箱托管的图标与背景
tools/    独立安装的官方工具资源包或用户自行维护的本地工具
logs/     当前运行日志
```

只备份清单时，优先导出 `.attconfig`。若还要迁移本地工具，需要单独备份相应 `tools/` 内容及其依赖；背景和本机快捷键不会被 `.attconfig` 带走。

## 13. 常见问题

### 本地工具无法启动

先确认项目路径存在。相对路径推荐写作 `tools/MAA/MAA.exe`。若提示需要官方工具资源包，请先在设置中安装资源包；若是自行添加的工具，请检查文件是否移动或编辑项目修正路径。

### 网站被识别为本地工具

目标必须以 `http://` 或 `https://` 开头；请补全协议头。

### 图标或背景原图删除后为什么仍能显示

这是正常行为。工具箱保存时已复制托管副本，只有该副本不再被项目、当前背景或历史背景引用时才会清理。

### 导入后本地项目不能启动

配置包不包含第三方程序。请在目标设备安装或复制对应工具和依赖文件，再检查项目路径。

### 拖拽后顺序没有变化

确认没有开启批量管理，并从卡片图标、标题或空白区域开始拖动，最后拖到目标项目卡片上。建议在“全部”分类、未搜索的状态下调整完整顺序。

### 定时任务没有在工具箱关闭后触发

确认任务已启用、勾选了“到达计划时间时启动工具箱”，且当前规则可转换为 Windows 任务计划。复杂 Cron 规则可能无法同步，请改为简易规则或在工具箱保持运行时使用。

# 阿洁的旅行工具箱使用教程

阿洁的旅行工具箱用于集中管理网站、本地程序、资料入口和个人常用工具。项目、分类、图标、背景、排序和定时任务都保存在工具箱自身目录中；不需要账号或联网服务才能使用基础功能。

> **开始前**：本地程序的相对路径一律以工具箱根目录为基准。推荐写成 `tools/程序目录/程序.exe`，并使用 `/`，这样在 Windows 与其他系统之间迁移时更稳定。

## 界面快速认识

- 顶部搜索框用于查找项目；支持中文、拼音和英文模糊匹配。
- 左侧拉出式侧栏用于切换分类；点击空白处或右侧遮罩可关闭侧栏。
- 每张正方形卡片代表一个项目，显示类型、图标、名称、简介、收藏、编辑与启动入口。
- 右上角“设置”集中放置配置、分类、批量管理、背景、定时任务和快捷键/快捷轮盘功能。
- 顶部“添加项目”用于创建新项目；“使用教程”可随时打开本说明。

## 项目与启动

### 新建项目

1. 点击顶部“添加项目”。
2. 填写名称与启动路径或网址；两项均必填。
3. 可选填写分类、简介并选择图标。
4. 点击“加入清单”。项目会加入当前配置源。

项目可不设置分类，此时会出现在“全部”中，但不会出现在任何自定义分类里。

### 本地工具与网站的识别

工具箱会自动判断项目类型：

- 以 `http://` 或 `https://` 开头的目标为**网站**，点击启动后使用系统默认浏览器打开。
- 其他目标均为**本地工具**，启动时相对于工具箱根目录解析路径。

例如：

```text
https://arkntools.app/
tools/MAA/MAA.exe
tools/贝娜的量角器/贝娜的量角器.exe
```

本地工具的文件不存在、被移动或路径填写错误时，将无法启动。请在编辑项目中修正路径；工具箱不会删除或修改原始程序文件。

### 编辑、删除、收藏与复制项目

点击卡片右上角“编辑”可修改名称、目标、分类、简介、图标与高级启动项。

- **删除此项目**：只删除当前配置源中的项目记录；不会删除原程序、网站、工具目录或原始图标文件。
- **收藏**：点击星标加入或移出“收藏”虚拟分类。收藏状态属于项目数据，会随配置导入导出。
- **导入到配置源**：在编辑窗口底部选择目标配置源，可复制当前项目过去。原项目保持不变；目标配置源缺少相同分类时会自动加入该分类。

### 高级启动（仅本地工具）

本地工具默认与网站一样，只有一个“启动”按钮。进入编辑窗口后，勾选“启用高级启动项”，保存后卡片会显示“启动”和“高级启动”两个按钮。

高级启动菜单包含：

- **以管理员权限启动**：通过 Windows UAC 请求管理员权限。只在确实需要管理员权限的工具上使用。
- **自定义命令启动**：可新增最多 20 条命令；每条命令要填写显示名称和 CMD 命令文本。例如：

```cmd
tools/MAA/MAA.exe --debug
```

自定义命令由 Windows `cmd.exe` 执行，工作目录是工具箱根目录，因此相对路径也以该目录为基准。命令可以执行任意系统操作，请只保存你理解且信任的命令。网站项目不会显示高级启动。

关闭“启用高级启动项”只会隐藏高级启动按钮，不会删除已经填写的命令；重新开启后仍可继续编辑和使用。

## 图标与简介

### 项目图标

支持 PNG、JPG、WebP、GIF、BMP 与 ICO。选择图标并保存后，工具箱会把图片复制到自身的 `static/images/custom/` 目录；之后即使删除外部原图，卡片仍可正常显示。

更换图标或删除项目时，如果旧图标已没有其他项目使用，工具箱会自动清理托管副本。内置资源和你手动放入目录的文件不会被自动删除。

### 简介显示

项目简介支持多行文字；卡片中空间有限，超出的内容可在简介区域滚动查看。编辑窗口会保留换行。

## 分类与配置源

### 分类管理

点击“设置”→“分类管理”可新增或删除自定义分类。

- 分类名称就是分类 ID，不能重复。
- “全部”和“收藏”是系统分类，不能删除。
- 删除一个自定义分类后，原本属于它的项目会变为“未分类”，项目本身不会删除。
- “全部”显示当前配置源全部已注册项目；“收藏”只显示已收藏项目。

### 配置源设置

配置源是一套独立、可迁移的工具工作流，包含项目、分类、排序、快捷轮盘布局和定时任务，适合把“日常使用”“测试”“不同游戏模式”等内容分开管理。

在“设置”→“配置源设置”中可以：

- 切换当前配置源；切换后界面只显示该源的项目。
- 新建配置源；可选择“创建时继承默认配置源”。继承会复制默认源的分类、项目、轮盘布局和定时任务定义；为避免重复触发，继承来的定时任务默认暂停，之后互不影响。
- 删除自定义配置源；默认配置源不可删除。删除源会删除该源的项目、分类、轮盘布局和定时任务，并取消该源已注册的 Windows 任务计划；不会删除其指向的本地程序。

## 搜索、排序与批量管理

### 搜索

顶部搜索支持名称、简介和分类的模糊搜索，并可识别：

- 中文输入，例如“量角器”；
- 拼音输入，例如 `liang jiao qi` 或拼音片段；
- 英文、缩写和数字，例如 `MAA`。

搜索结果仍会受当前分类筛选影响。按 `Ctrl + K`（macOS 为 `⌘ + K`）可快速聚焦搜索框。

### 拖拽排序

在非批量管理状态下，可以拖拽项目卡片来调整顺序：

1. 从卡片的图标、标题或空白区域按住并拖动；按钮、输入框和可滚动简介不作为拖拽起点。
2. 将它拖到目标项目卡片上；目标卡片会出现橙色描边。
3. 松开鼠标后，**两张卡片会交换位置**，其他项目不会被移动。

顺序会保存到当前配置源。切换分类、搜索、重启工具箱、导出再导入同一配置源后，已保存的排序会保留。

### 批量管理

点击“设置”→“批量管理”后，每张卡片会出现选择按钮。

1. 勾选一个或多个项目。
2. 选择“移动到分类”“复制到分类”或“删除”。
3. 完成后点击“完成”退出批量模式。

“移动到分类”会改变原项目分类；“复制到分类”会创建项目副本，原项目保持不变；“删除”只删除当前配置源中的项目记录。选择一个不存在的分类时，可在弹窗中直接新建。

## 背景图片

在“设置”→“自定义背景图片”中可设置界面背景：

- 点击区域选择图片，或把图片拖进区域；支持 PNG、JPG、WebP、GIF、BMP。
- 保存后图片会被复制到工具箱自身目录，原图删除不会影响当前背景。
- 工具箱最多保留 10 张历史背景；点击缩略图可切换。
- 点击“恢复默认背景”会恢复内置背景。无项目与历史记录引用的背景托管文件会自动清理。

## 配置导入与导出

### 导出配置

点击“设置”→“导出配置”，选择一个配置源，然后导出 `.attconfig` 文件。

导出包是 ZIP 格式，包含该配置源的项目、分类、收藏状态、排序、高级启动设置、自定义命令、托管图标、快捷轮盘项目布局和全部定时任务定义。它**不包含**工具箱程序、`tools/` 里的本地工具、日志、外部原图，以及本机全局快捷键、轮盘位置与轮盘尺寸。

### 导入配置

点击“设置”→“导入配置”，选择 `.attconfig` 文件后可选择三种方式：

- **增量导入（默认）**：创建新的配置源导入，不影响现有清单。
- **合并导入**：将导入项目与分类加入当前自定义配置源。
- **覆盖导入**：用导入内容替换当前自定义配置源的项目和分类。

默认配置源不能被合并或覆盖；如需保留现有内容，请优先使用增量导入。导入只写入配置，不会自动启动任何项目或命令。导入的定时任务会完整保留，但**默认暂停**，不会立刻创建 Windows 任务计划；请在定时任务管理中确认后手动启用。

增量导入与覆盖导入会恢复导出时的完整项目排序；合并导入会保留目标配置源现有项目的顺序，并按原排序追加导入的项目。跨设备迁移本地工具项目时，目标设备仍需自行准备对应 `.exe` 与文件夹，并让项目路径有效。`n`n旧版本配置包即使缺少分类、排序、轮盘布局、定时任务或新项目字段，也可以继续导入：工具箱会分别使用空分类、稳定排序、空轮盘和空任务等安全默认值。缺失项目图标不会阻止项目导入；无法解析的单个项目会被跳过，其余内容仍可使用。

## 定时启动管理（Windows）

“设置”→“定时启动管理”允许保存多份定时任务。每份任务绑定一个配置源，并包含按顺序执行的项目队列。

### 创建任务

1. 填写任务名称，选择配置源。新建任务默认勾选“到达计划时间时启动工具箱”。
2. 选择时间配置：
   - **简易设置**：每天、每周或每月。每周可勾选多个星期。
   - **Cron 高级设置**：五段式 `分 时 日 月 周`，例如 `0 9 * * 1-5`。
3. 从项目选择器逐个加入启动队列。新加入项目默认在启动后等待 10 秒；可为每一步单独调整等待时间、删除或调整队列顺序。最后一项不等待。
4. 保存任务。

网站始终按普通方式打开；本地工具可以为单个步骤选择管理员权限启动，Windows 会弹出 UAC 确认。

### 触发设置

- **启用此任务**：关闭后，该任务不会按时间触发。
- **到达计划时间时启动工具箱**：适用于可转换的简单 Cron 规则。工具箱会注册 Windows 任务计划，使工具箱关闭时也能在到点后启动并执行任务；复杂规则可能无法转换，会提示关闭该项或改用简易设置。
- **工具箱启动后立即执行一次**：每次工具箱启动时，只要任务启用，就立即执行一次。
- **按固定间隔重复触发**：基础时间首次触发后，再按设置的分钟间隔重复执行。

多个任务同时触发会依次进入执行队列。同一任务尚未结束时，不会并发重复运行。

## 快捷键与快捷轮盘

从设置菜单打开 **快捷键与快捷轮盘设置**。该功能默认关闭，开启后会注册 Windows 全局快捷键，因此旅行箱在后台时也能响应。

### 项目组合快捷键

选择对应配置源后，点击项目右侧的“点击设置快捷键”，在弹出的录制窗口中直接按下组合键或单个按键，例如 `Ctrl+Alt+M`。可使用“清除快捷键”移除绑定。保存后会按该项目原有规则正常启动：网站打开浏览器，本地工具按普通方式启动；不会自动使用管理员权限或自定义命令。

### 快捷轮盘

开启轮盘后，点击“设置快捷键”，在录制窗口中按下唤起键，再从当前配置源选择 **圆心 1 项** 和 **外围 9 项**。轮盘项目布局属于当前配置源，随 `.attconfig` 导入导出。可用大小滑动条、九宫格位置和横/纵百分比微调来调整本机轮盘外观；点击“预览位置与大小”可临时显示真实轮盘约 6 秒。按下唤起键时，旅行箱会显示独立的无边框透明置顶窗口。点击项目即可启动；按 `Esc`、再次按唤起键、右键或让轮盘失焦即可关闭。

快捷键不主动抢占其他程序：若 Windows 或其他应用已占用某个组合，旅行箱会保留设置但提示该快捷键未注册。系统保留键同样可能无法注册。普通单键也允许填写，但会影响打字和其他软件操作，请谨慎使用。全局快捷键、轮盘唤起键、轮盘位置与尺寸保存于本机 `config/shortcuts.json`，不会随 `.attconfig` 配置源导出；轮盘项目布局和定时任务则保存在各配置源目录中。
## 数据位置与备份建议

工具箱的可变数据位于程序同级目录，主要包括：

```text
config/   配置源、背景与全局快捷键/轮盘外观设置
items/    各配置源的项目文件
static/   托管图标与背景
logs/     日志
tools/    随发行包提供或自行放入的本地工具
```

移动工具箱或备份时，建议整体保留这些目录与主程序的相对关系。只备份清单时，优先使用 `.attconfig` 导出；要保留本地工具，还应另行备份 `tools/` 及其依赖文件。

## 常见问题

### 查看与导出运行日志

点击“设置”→“查看运行日志”，可实时查看工具箱本次及近期运行事件；窗口打开期间会每 2 秒刷新一次，关闭后立即停止刷新以避免额外占用。日志按 `DEBUG`、`INFO`、`WARNING`、`ERROR`、`CRITICAL` 五级记录，可在窗口内筛选最低显示等级。时间以本机易读的 `年-月-日 时:分:秒.毫秒` 显示。点击“导出日志”后自行选择保存位置，工具箱会生成便于反馈的 `.txt` 文件。

日志在程序运行期间写入工具箱根目录的 `logs/runtime-YYYY-MM-DD.ndjson`；每次启动时会先清除上一轮运行的日志，因此只保留本次运行的记录。导出的 TXT 由你自行选择位置保存，不会被自动删除。日志会自动隐藏令牌、密码、Cookie、完整外部网址、深层本地路径、原始截图及窗口句柄等敏感内容；请仍在发送前自行确认导出文件不包含不希望分享的信息。开发者可用 `npm run logs:pretty < logs/runtime-YYYY-MM-DD.ndjson` 将原始结构化日志格式化后阅读。

“启动时检查更新”是可保存的用户偏好，即使当前开发环境或发行包尚未配置 GitHub 更新源，也可提前自行决定安装版将来是否自动检查。未配置更新源时，手动检查按钮会保持不可用，并明确提示这不会影响工具箱正常使用。

### 本地工具无法启动

检查路径是否存在；相对路径以工具箱根目录为基准。推荐使用例如 `tools/MAA/MAA.exe` 的写法。若移动过工具箱或工具目录，请恢复相对目录关系，或编辑项目改为正确的新路径。

### 网站被识别为本地工具

只有以 `http://` 或 `https://` 开头的地址会被识别为网站。请补全协议头。

### 图标或背景的原图删除后为什么仍可显示

这是正常行为。保存时工具箱已复制一份托管副本；只有该副本不再被任何项目或背景历史使用时，才会清理。

### 导入后本地项目不能启动

`.attconfig` 不包含第三方程序。请在目标设备准备对应工具文件，并检查项目路径。

### 拖拽后顺序没有变化

请确认不在批量管理状态，并从卡片图标、标题或空白区域开始拖拽，最后拖到另一张项目卡片上。卡片只会与目标卡片交换位置。
